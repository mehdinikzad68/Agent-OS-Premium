## Built (all committed to git)

- **Phase A — packaging**: `pyproject.toml` (agent-os 0.2.0, zero deps, Python>=3.11,
  console script `agent-os`), `.gitignore`, `git init` + baseline commits.
- **Phase B — HTTP API** (`agent_os/api.py`): loopback-only, bearer-token auth
  (fail-closed: `serve` refuses without a token unless `--insecure`),
  read+write endpoints, named executor registry (unknown executor refused before
  work). Fixed a real bug found by socket smoke test: SQLite connection used
  across ThreadingHTTPServer threads -> store now uses
  `check_same_thread=False` + an in-process RLock on every method.
- **Phase C — UI** (`agent_os/web/index.html`): single-file, offline (no CDN), RTL
  Persian dashboard — missions, jobs, approval inbox (grant/deny), live event feed,
  status/capability panel, token connect. Added `/api/missions/{id}/activate`.
  Fixed a real bug found by e2e: the UI shell required the bearer token, which a
  browser cannot send -> UI shell is now public on loopback while all `/api/*`
  stays token-protected (regression test added).
- **Phase D — real executor** (`agent_os/adapters/subprocess_executor.py`), GATED
  behind `--enable-subprocess --source-workspace`: copies the source to a fresh
  disposable dir (source never modified), hard timeout (timeout => not success),
  evidence to files instead of pipes, honest test-signal detection, and `command`
  included in the job manifest hash so changing it invalidates the grant.
  Added schema **v2** with a real migration path (`jobs.command`).
- **Phase E — release artifacts**: product `README.md`, `RUNBOOK.md` (ops: start/stop,
  token rotation, backup/recovery, incident table, upgrade), `READINESS.md`
  (evidence table + honest non-capabilities + integration gates), plus
  `e2e_verify.py` (10-step real-HTTP product verification).

## Audit round after first release docs (real gaps found and fixed)

- Evidence was NOT durable: completion events stored only job_id/attempt. Fixed —
  evidence is now persisted into the append-only event log (strings truncated at
  16 KB) and served via `GET /api/jobs/{id}/evidence` (E2E step 11 + tests).
- UI job actions were dead code (`showJob` built buttons but never rendered them).
  Fixed — job detail card renders state-appropriate actions
  (request-approval / dispatch / reconcile) + evidence viewer; refresh keeps it live.
- Added request body cap (1 MB → 413) as cheap hardening; socket test added.
- Harness quirk worked around: `tempfile.mkdtemp` dirs (mode 0o700) are
  write-denied by the sandbox — the executor now uses `Path.mkdir` with uuid names.
- Stale `.testtmp/sandboxes/*` dirs from the pre-fix probe are stuck with
  sandbox-denied ACLs; harmless, gitignored, cannot be deleted from inside.
