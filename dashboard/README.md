# Agent-OS Neural Command

Reconstructed Vite + React source for the Agent-OS Neural Command artifact.

## Run locally

```bash
npm install
npm run dev
```

Build for production with:

```bash
npm run build
```

The app uses React 18, Vite, Tailwind CSS, Canvas 2D, and lucide-react. The original Google Fonts import is preserved in `src/index.css`. Optional self-hosted WOFF2 declarations are included there as a commented block.
